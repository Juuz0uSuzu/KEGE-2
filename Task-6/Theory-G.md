## 1. Базовые команды модуля `turtle`

### Подключение и настройка окна
```python
from turtle import * # Подключение всех методов (звёздочка обязательна!)

screensize(2000, 2000) # Задаёт размеры полотна (ширина, высота), чтобы сетка не обрезалась
tracer(0)              # Отключает анимацию отрисовки (0 — выкл, 1 — вкл)
```

### Движение и повороты
> **Важно:** Черепаха изначально смотрит **вправо** (вдоль положительного направления оси $OX$). Все повороты и шаги выполняются относительно текущего направления её головы.

| Действие | Короткая команда | Полная команда | Описание |
| :--- | :--- | :--- | :--- |
| **Вперёд** | `fd(step)` | `forward(step)` | Движение вперёд на `step` пикселей |
| **Назад** | `bk(step)` | `backward(step)` | Движение назад на `step` пикселей |
| **Вправо** | `rt(angle)` | `right(angle)` | Поворот по часовой стрелке на `angle` градусов |
| **Влево** | `lt(angle)` | `left(angle)` | Поворот против часовой стрелки на `angle` градусов |

### Управление пером и сетка
```python
up()   # или penup()   — поднять перо (черепаха не оставляет след)
down() # или pendown() — опустить перо (черепаха рисует линию)

teleport(x, y)      # Мгновенное перемещение в точку (x, y) без рисования следа (Python 3.12+)
goto(x, y)          # Классический аналог (если перо поднято через up())
dot(size, 'red')    # Ставит точку размером size и цветом ('red' или '#FF0000')
```

### Завершение программы
```python
update() # Обязательно вызывать при использовании tracer(0), чтобы отрисовать картинку
done()   # Замораживает окно Черепахи, чтобы оно не закрылось сразу после выполнения
```

## 2. Формулы для прямоугольников (аналитический метод)

Пусть даны два пересекающихся прямоугольника:
* **Фигура 1:** стороны $S_1 \times S_2$
* **Фигура 2:** стороны $S_3 \times S_4$
* **Область пересечения** в цикле задаётся диапазонами:
  * по оси абсцисс ($OX$): `range(L1, R1)` (количество узлов по $X$ равно $R_1 - L_1$, длина стороны пересечения равна $R_1 - L_1 - 1$)
  * по оси ординат ($OY$): `range(L2, R2)` (количество узлов по $Y$ равно $R_2 - L_2$, длина стороны пересечения равна $R_2 - L_2 - 1$)

> **Памятка:** Формулы для объединения работают корректно, если один прямоугольник не лежит целиком внутри другого и пересечение не пустое.

| Что нужно найти | Формула | Примечание |
| :--- | :--- | :--- |
| **Точки в объединении** *(с учётом линий)* | $(S_1 + 1)(S_2 + 1) + (S_3 + 1)(S_4 + 1) - (R_1 - L_1)(R_2 - L_2)$ | Сумма точек обеих фигур минус общие точки |
| **Точки в объединении** *(без учёта линий)* | $(S_1 - 1)(S_2 - 1) + (S_3 - 1)(S_4 - 1) - (R_1 - L_1 - 2)(R_2 - L_2 - 2)$ | Будь аккуратен: стороны пересечения не должны лежать на границах исходных фигур |
| **Точки в пересечении** *(с учётом линий)* | $(R_1 - L_1) \cdot (R_2 - L_2)$ | Произведение длин `range` по $X$ и по $Y$ |
| **Точки в пересечении** *(без учёта линий)* | $(R_1 - L_1 - 2) \cdot (R_2 - L_2 - 2)$ | Вычитаем по 2 крайние точки (границы) с каждой оси |
| **Площадь пересечения** | $(R_1 - L_1 - 1) \cdot (R_2 - L_2 - 1)$ | Произведение длин сторон прямоугольника пересечения |
| **Площадь объединения** | $(S_1 \cdot S_2) + (S_3 \cdot S_4) - (R_1 - L_1 - 1)(R_2 - L_2 - 1)$ | Сумма площадей минус площадь пересечения |
| **Периметр пересечения** | $2 \cdot ((R_1 - L_1 - 1) + (R_2 - L_2 - 1))$ | Удвоенная сумма сторон пересечения |
| **Периметр объединения** | $2(S_1 + S_2) + 2(S_3 + S_4) - P_{\text{пересечения}}$ | Сумма периметров фигур **минус** периметр пересечения |

## 3. Базовый шаблон для Задания №6 (перебор по сетке)

```python
from turtle import *

screensize(2000, 2000)
tracer(0)
m = 20  # Масштаб (количество пикселей в 1 единице сетки)

# 1. Алгоритм из условия задачи (все шаги умножаем на m!)
down()
for _ in range(4):
    fd(10 * m)
    rt(90)

# 2. Отрисовка координатной сетки с целочисленными точками
up()
for x in range(-20, 20):
    for y in range(-20, 20):
        teleport(x * m, y * m)
        dot(4, 'red')

update()
done()
```
