> **Важно:** перед шаблоном всегда ставим префикс `r'...'` (*raw string*), чтобы Python не воспринимал обратный слэш `\` как спецсимвол (например, `\n` или `\t`).

---

## 1. Подключение и базовые функции (`re`)

```python
from re import *

data = '9 лет 16 лет 13   лет 1год'
pattern = r'\d{1,2} *(?:лет|год)'

# finditer возвращает итератор объектов Match (удобно для поиска максимальной длины)
matches = [x.group() for x in finditer(pattern, data)]
print(matches)  # ['9 лет', '16 лет', '13   лет', '1год']
```

| Функция | Что возвращает | Особенности для ЕГЭ |
| :--- | :--- | :--- |
| `finditer(pattern, data)` | Итератор совпадений (`Match`) | Текст совпадения достаётся через `.group()`, длина — `len(x.group())`. |
| `findall(pattern, data)` | Список строк (`list[str]`) | Если в шаблоне есть обычные скобки `(...)`, вернёт **только** содержимое скобок! |

## 2. Метасимволы и классы символов

### Специальные последовательности

| Обозначение | Что означает |
| :--- | :--- |
| `\d` | Любая цифра (`0–9`) |
| `\D` | Любой символ, **кроме** цифры |
| `\s` | Любой пробельный символ (пробел, табуляция, перенос строки) |
| `\S` | Любой непробельный символ |
| `\w` | Любая буква, цифра или нижнее подчёркивание `_` |
| `.` | Любой один символ (кроме переноса строки `\n`) |

### Наборы и диапазоны (`[...]`)

| Обозначение | Что означает |
| :--- | :--- |
| `[0-9]` | Любая цифра от `0` до `9` |
| `[a-z]` | Любая **строчная** латинская буква |
| `[A-Z]` | Любая **заглавная** латинская буква |
| `[0-9a-zA-Z]` | Любая цифра или латинская буква любого регистра |
| `[а-яё]` | Любая строчная буква кириллицы (включая `ё`) |
| `[^0-9]` | **Исключение:** любой символ, **кроме** цифры (`^` внутри квадратных скобок означает отрицание) |

## 3. Квантификаторы (количество повторений)

Ставятся сразу после символа или группы и определяют, сколько раз они могут повторяться подряд.

| Квантификатор | Эквивалент | Значение |
| :--- | :--- | :--- |
| `{m}` | — | Ровно `m` повторений |
| `{m,n}` | — | От `m` до `n` повторений включительно |
| `*` | `{0,}` | `0` и более повторений (может отсутствовать) |
| `+` | `{1,}` | `1` и более повторений (минимум один раз) |
| `?` | `{0,1}` | `0` или `1` повторение (необязательный элемент) |

---

## 4. Скобочные группы и ловушки ЕГЭ

| Конструкция | Пример | Как работает |
| :--- | :--- | :--- |
| `(A\|B)` | `(лет\|год)` | Выбор одного из вариантов. **Внимание:** `findall` вернёт только то, что внутри скобок. |
| `(?:A\|B)` | `(?:лет\|год)` | **Незахватывающая группа** — группирует варианты, но `findall` возвращает всю найденную строку целиком. |
| `(?=...)` | `(?=(ABA))` | **Пересекающийся поиск** (*lookahead*). Если в строке `ABABA`, обычный поиск найдёт только первый `ABA`, а `(?=(ABA))` — оба! |

## 5. Готовый шаблон для Задания №24

```python
from re import *

with open('24.txt') as f:
    data = f.readline().strip()

# Пример: найти максимальную длину цепочки из пар вида (согласная + гласная)
pattern = r'(?:[BCDFGHJKLMNPQRSTVWXYZ][AEIOUY])+'

ans = max(len(x.group()) for x in finditer(pattern, data))
print(ans)
```
