## 1. Перевод из 10-й системы счисления

### Встроенные функции и `f`-строки
Функции `bin()`, `oct()`, `hex()` принимают `int` и возвращают `str` с префиксом (`0b`, `0o`, `0x`), поэтому срез `[2:]` обязателен. Через `f`-строки префикс не добавляется.

| Система счисления | Через функцию | Через `f`-строку | Пример для `N = 25` |
| :--- | :--- | :--- | :--- |
| **Двоичная (2)** | `bin(N)[2:]` | `f'{N:b}'` | `'11001'` |
| **Восьмеричная (8)** | `oct(N)[2:]` | `f'{N:o}'` | `'31'` |
| **Шестнадцатеричная (16)** | `hex(N)[2:]` | `f'{N:x}'` / `f'{N:X}'` | `'19'` / `'19'` |

### Перевод в любую систему (`2 <= sys <= 9`)
```python
def convert(num, sys):
    res = ''
    while num != 0:
        res += str(num % sys)
        num //= sys
    return res[::-1] if res else '0'
```

### Перевод в любую систему (`2 <= sys <= 36`)
В `string.printable` первые 36 символов идут в порядке `0–9` и `a–z`.
```python
from string import printable as alph

def convert2(num, sys):
    res = ''
    while num:
        res += alph[num % sys]
        num //= sys
    return res[::-1] if res else '0'
```

## 2. Перевод в 10-ю систему счисления

Функция `int(строка, основание)` работает для любых систем с основанием от `2` до `36`.

```python
print(int('101', 2))   # 5
print(int('201', 3))   # 19
print(int('f01', 16))  # 3841 (регистр букв не важен)
```

## 3. Срезы строк

Пример на строке `data = '1234567'`:

| Задача | Срез | Результат |
| :--- | :--- | :--- |
| Взять **2 первых** символа | `data[:2]` | `'12'` |
| Убрать **2 первых** символа (взять без них) | `data[2:]` | `'34567'` |
| Взять **2 последних** символа | `data[-2:]` | `'67'` |
| Убрать **2 последних** символа (взять без них) | `data[:-2]` | `'12345'` |

## 4. Сумма цифр числа

```python
# 1. Двоичная система
num_bin = '1010'
sum_bin = num_bin.count('1')

# 2. Любая система до 10 включительно
num_dec = '1210'
sum_dec = sum(map(int, num_dec))

# 3. Любая система до 36 включительно
num_36 = 'AF5'
sum_36 = sum(map(lambda x: int(x, 36), num_36))
```

## 5. Базовый шаблон для Задания №5

```python
ans = []
for N in range(1, 10000):
    R = f'{N:b}'  # или convert2(N, base)
    
    # Условия преобразования строки R
    if R.count('1') % 2 == 0:
        R = '10' + R[2:]
    else:
        R = '11' + R[2:]
        
    R = int(R, 2)
    if R > 50:
        ans.append(N)

print(min(ans))
```
